# tg-onboarding

Client onboarding & post-sale success tool for **Travelgenix** — a branded welcome portal that guides each new client from signing through to confident, independent use of the platform.

Built to beat post-go-live "wilting": a visible seven-phase journey with progress, checklists, embedded training, and a confidence gate before go-live.

## Status

Phase 1 (MVP client welcome portal) — screen 1 built, running on mock data. See `AGENTS.md` for the full project brief, locked decisions, and current open questions.

## Development

```bash
npm install      # install dependencies
npm run dev      # dev server at http://localhost:3000
npm run build    # production build
npm run lint     # eslint
```

## Stack

Next.js (App Router, TypeScript, Tailwind v4) · Airtable (data layer, mocked for now) · Luna AI (contextual help, stubbed) · Vercel (team: agendasgroup)
